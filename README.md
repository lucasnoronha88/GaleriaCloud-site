# Galeria Cloud — site público

Site estático em português para apresentar o aplicativo, orientar participantes do teste fechado e publicar a política de privacidade.

## Publicação no GitHub Pages

1. Criar um repositório público separado do repositório privado do aplicativo.
2. Enviar os arquivos desta pasta para a raiz da branch `main`.
3. Em **Settings → Pages**, selecionar **Deploy from a branch**, branch `main`, pasta `/ (root)` e salvar.
4. Aguardar o endereço do GitHub Pages aparecer em **Settings → Pages**.

Os botões de teste levam ao grupo de testadores e à página de participação do Google Play. A instalação fica disponível pelo Google Play depois de entrar no teste.
